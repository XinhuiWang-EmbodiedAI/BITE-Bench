# BITE Collect — 浏览器交互原型

这是 BITE-Bench 项目的人类偏好采集界面 **演示原型**，尚非正式实验系统。

## 本地试玩

直接用浏览器打开 `index.html` 即可，无需安装 Python、Node 或任何依赖。

- 8 道食物二选一（可选择平局/跳过）
- 4 道食物 0–10 口味校准评分
- 2 道完整日菜单选择（仅演示页面和阶段区分）
- 简单口味画像，以及演示 JSON 导出
- 非 AI 协作者看板视觉原型

## 隐私与研究限制

- 页面不向任何服务器发送数据；回答仅存在当前页面内存中，刷新后消失。
- 导出的 `demo_only: true`、`research_eligible: false` 数据 **不得并入正式研究集**。
- 页面食品标准份量、菜品图片及营养数据尚未与 FoodBench-48 正式数据库衔接。菜单没有真实营养值。
- 页面没有用户认证、真正的采集 API、数据库、线上部署、撤回机制和正式研究知情同意。
- 真实研究招募前，应完成适用的伦理/隐私流程，使用经审核的食品数据、冻结训练/测试协议、受控的存储及安全部署。

## 正式版技术集成建议

保留 `BITE-Bench/docs/RESEARCH_METHOD.md`、`CODEX_PLAYBOOK.md`、`AUTOMATION_ADDENDUM.md` 中的科学约束，新增 `apps/bite-collect/` 子系统。正式版分为参与者移动端、采集员后台、研究数据导出、匿名会话/撤回、审计日志、试验版本与分组管理。前端与受控 API/数据库部署在 HTTPS 网站，RTX 5060 只进行离线训练/评价。
